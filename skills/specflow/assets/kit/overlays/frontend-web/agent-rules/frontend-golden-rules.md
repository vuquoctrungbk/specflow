# Frontend Golden Rules

<!-- fill: Copy to .claude/rules/frontend-golden-rules.md at Stage 2. paths lists the UI source directories per ARCHITECTURE §4, one glob per element. assembled_from records "overlays/frontend-web/agent-rules/frontend-golden-rules.md@<template_version>" and the stack profile used. -->

- Separate the layers: a route only fetches initial data and composes the feature's components; display logic lives in the feature directory; shared UI components contain no business logic and do not call the API.
- {{RENDER_BOUNDARY_RULE}}
- Every API call goes through the client generated from OpenAPI; MUST NOT hand-write response types or call the API with a URL built by string concatenation.
- Each screen implements all five UI states per the table in SPEC §3; MUST NOT leave a blank screen while loading or on error.
- Every display string is fetched through a locale string key; MUST NOT hard-code display text in a component.
- MUST NOT write raw color, spacing, radius or font size in UI code, including arbitrary values of the utility CSS tool; use only the tokens of `docs/design-system/tokens.json` through the token mapping file (CSS variables). That mapping file, hand-written or generated by a tool, is the only place allowed to hold raw values and MUST match `tokens.json`. The theme of the UI library changes only through tokens, not by editing the library's theme file directly.
- Prices, amounts, permissions and status are displayed from the data the API returns; MUST NOT compute these values and then send them to the API.
- A write action locks while submitting; each submitted content has its own `Idempotency-Key`. After a network error, a timeout or `5xx`, the form locks editing and resubmits only that exact content with the same key until a definitive response arrives.
- MUST NOT store tokens, secrets or personal data in `localStorage` or `sessionStorage`; environment variables sent to the browser contain no secret.
- Accessibility: semantic tags before ARIA, every field has a label, errors are tied to their field, every action can be done with the keyboard; full criteria in `specflow/CONVENTIONS.md` §10.2.
